# Auto Cost V1 验收清单

状态：开发与自验收基线  
版本：1.0  
日期：2026-08-26

## A. 构建与安全基线

- [ ] `npm run lint` 通过。
- [ ] 类型检查与 `npm run build` 通过。
- [ ] 仓库不包含原始工资 Excel、明文 API 密钥、生产数据库地址或生产登录密码（约定的环境测试账号除外）。
- [ ] 未登录访问受保护页面时跳转到 `/login`。
- [ ] Cookie 为 HttpOnly、SameSite=Lax；生产环境启用 Secure。
- [ ] 页面、API 和运行日志均不输出逐人工资明细。

## B. 登录

- [ ] 使用 `admin / admin123` 可以登录并进入仪表盘。
- [ ] 错误密码不能登录，并显示中文错误。
- [ ] 退出登录后无法访问受保护页面。
- [ ] 登录成功与失败均产生审计事件，审计中不含密码。
- [ ] 钉钉未配置时登录页安全禁用扫码入口，不向页面输出 Client Secret。
- [ ] 钉钉 OAuth 回调缺少、伪造或过期 `state` 时拒绝登录并记录审计。
- [ ] 财务白名单内的企业成员扫码后可以进入仪表盘。
- [ ] 非本企业成员、错误企业和不在财务白名单内的成员均不能登录。
- [ ] 会话和日志不保存钉钉 AccessToken、Client Secret 或 OAuth 授权码。

## C. Excel 导入

- [ ] 能上传参考文件 `2607工资.xlsx`。
- [ ] 系统只读取第一个工作表。
- [ ] 能识别期间、姓名和“公司人力总成本”。
- [ ] 导入预览显示月份、总行数、有效行数和错误行数。
- [ ] 公式错误、空成本或非数值不会被当成 0。
- [ ] 存在错误时不能提交，并能看到行号及原因。
- [ ] 修正或使用有效测试文件后可以提交。
- [ ] 重复文件摘要不能被静默重复导入。
- [ ] 原始文件不写入数据库和代码仓库。

## D. 工资管理

- [ ] 表格左侧为部门、姓名，右侧月份按最近到最早排列。
- [ ] 金额采用人民币格式展示。
- [ ] 能按部门或姓名搜索。
- [ ] 可以手工修改月度成本。
- [ ] 不填写原因时不能保存手工修改。
- [ ] 保存后仪表盘和 API 使用新金额。
- [ ] 操作审计保存修改前金额、修改后金额、原因和操作者。

## E. 仪表盘

- [ ] 显示最新月份成本、本季度成本、本年度成本、在职人数和人均成本。
- [ ] 最近 12 个月趋势与工资数据一致。
- [ ] 部门分布合计与最新月份总额一致。
- [ ] 没有数据时显示导入引导，不出现异常或空白页。

## F. 人员管理

- [ ] 展示人员 ID、姓名、部门、工号、状态、来源和同步时间。
- [ ] 支持姓名、工号或部门搜索。
- [ ] 未配置钉钉凭证时同步安全失败，并记录审计。
- [ ] 真实同步可以递归读取部门、分页读取成员，并记录同步数量和审计。
- [ ] 优先按钉钉 userId，其次按唯一工号或唯一姓名关联已有工资人员，保持系统人员 ID 不变。
- [ ] 离职人员保留历史成本，不被物理删除。
- [ ] 页面明确显示钉钉真实同步是否已配置。

## G. 接口密钥

- [ ] 可以创建一个具名的 Security 字符串/API 密钥。
- [ ] 完整密钥只在创建成功时显示一次。
- [ ] 后续列表仅显示前缀和末四位。
- [ ] 数据仓库不保存明文密钥。
- [ ] 可以停用密钥；停用后请求返回 `UNAUTHORIZED`。

## H. 聚合查询 API

- [ ] 请求必须使用 `Authorization: Bearer <key>`。
- [ ] 正常的两人查询只返回整批 `totalCost`。
- [ ] 响应中没有逐人金额或逐人计算明细。
- [ ] 日期按闭区间和自然日计算。
- [ ] 跨月查询正确拆月并汇总。
- [ ] 同一个人员重复两次返回 `DUPLICATE_EMPLOYEE`。
- [ ] 只有一名有效人员返回 `MIN_PARTICIPANTS`。
- [ ] 零天、非法日期返回 `INVALID_DATE_RANGE`。
- [ ] 缺少工资月份返回 `MISSING_MONTHLY_COST`。
- [ ] 某人员贡献为 0 返回 `ZERO_CONTRIBUTION`。
- [ ] 某人员贡献低于整批 10% 返回 `CONTRIBUTION_TOO_LOW`。
- [ ] 高度相似的差分查询返回 `DIFFERENCING_RISK`。
- [ ] 所有成功或失败请求都有 `requestId` 和查询日志。

## I. 日志与审计

- [ ] 接口管理页面可查看来源、IP、人数、状态、原因、耗时和结果总额。
- [ ] 失败记录显示稳定错误码和中文说明。
- [ ] 查询日志不包含明文密钥和逐人金额。
- [ ] 操作审计可以查看登录、导入、编辑、同步和密钥操作。

## J. 浏览器与部署验收

- [ ] 登录、仪表盘、工资、人员、接口、审计页面均可打开。
- [ ] 无 Next.js 错误覆盖层。
- [ ] 浏览器控制台无未处理错误。
- [ ] 关键交互可通过键盘操作。
- [ ] 桌面和手机宽度下没有不可用的遮挡。
- [ ] Vercel 生产部署状态为 READY。
- [ ] 生产环境连接持久化数据库。
- [ ] 生产地址 HTTP 200，登录后关键页面可访问。
- [ ] 生产运行错误扫描无新增错误。

## K. 自验收记录

开发完成后在 `docs/ACCEPTANCE_REPORT.md` 中逐项记录：

- 测试时间与代码提交号。
- 每一大项的 PASS/FAIL。
- 使用的命令或浏览器证据。
- 已知限制。
- 是否允许部署。

只有 A–J 的阻断项全部 PASS，才允许部署到 Vercel。
